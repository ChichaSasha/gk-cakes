C-CUSTOM r4 preservation: each frozen request summary retains the exact inspiration
image revision/bytes and requested differences through catalog replacement/archive.
Authorized customer and associated manager can view that saved image; temporary
image URL expiry offers authorized refresh, and foreign access returns404. A
cleanup race returns409 REFERENCE_UNAVAILABLE before freezing if the image is no
longer retainable. GK-027 tests the complete image A-to-B/archive scenario under
K02A; Creator GK-005 decides explicit deletion/retention.

C-GALLERY/C-DETAIL/C-CUSTOM r5: rendered images carry immutable image_revision_id.
Selecting an inspiration carries that exact ID through the paired custom draft
and versioned summary request. If A changes to B before freezing, keep A or show
REFERENCE_UNAVAILABLE/reselect; never silently substitute B. Generic requests
use no image pair. GK-022/027/028 verify this boundary under K02A.
