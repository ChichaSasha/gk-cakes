## Context and options

PostgreSQL durable jobs/inbox plus provider tools versus message broker/custom scheduler; versioned recipe snapshots versus mutable historical recipes; component release tags versus shared release.

## Recommendation

Transactional notification intents, evidence-based statuses and bounded retries; immutable recipe and costing snapshots, explicit actual inventory movements. Propose ui-vX.Y.Z/api-vX.Y.Z, separate target authorization, one controlled migration, additive compatibility.
